# Task Manager Demo - Low-Code Developer Portfolio

> A demonstration project showcasing JavaScript, CSS, and data modeling skills for low-code platform development.

## Purpose

This project demonstrates the core skills required for hybrid low-code + JavaScript development:
- **Data Modeling**: Entity relationships and field logic
- **JavaScript**: Custom logic extending beyond visual builders
- **API Integration**: External service communication
- **CSS**: Styling and layout (Nice to Have skill)

## Project Structure

```
low-code-demo/
├── README.md              # This file
├── data-model.js          # Data structures & relationships
├── api-integration.js     # API integration examples
├── task-utils.js          # JavaScript utility functions
└── styles.css             # Styling for task components
```

## Skills Demonstrated

| Skill | File | Description |
|-------|------|-------------|
| Data Modeling | `data-model.js` | Entity relationships, field logic, validation |
| JavaScript | `task-utils.js` | Priority calculation, validation, sorting |
| API Integration | `api-integration.js` | REST API calls, webhook notifications |
| CSS | `styles.css` | Component styling, responsive design |
| Clean Code | All files | Comments, documentation, maintainability |

## How to Run

1. Clone this repository
2. Open `index.html` in a browser (create one linking all JS/CSS files)
3. Or import individual files into your low-code platform's code editor
